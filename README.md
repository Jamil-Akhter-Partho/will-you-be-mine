# 💗 Will You Be Mine?

> A little interactive journey for someone very special. ❤️

**Will You Be Mine?** is a romantic, interactive web experience built entirely with **HTML, CSS, and JavaScript**.

What starts as a few playful questions gradually turns into a personalized date-planning journey — ending with one very special question. 💍

---

## ✨ Features

- 💗 Romantic modern UI
- 📱 Fully responsive design
- ✨ Smooth card-to-card transitions
- 💫 Animated gradient background
- ❤️ Floating hearts
- 🎭 Playful interactions
- 🚫 Escaping "No" buttons
- 💕 Interactive date preferences
- 💳 Playful payment question
- 💖 Love explosion animations
- 💍 Final proposal interaction
- 🎉 "It's a Date!" celebration screen
- ⚡ No database required
- 🌐 100% static website

---

## 🛠️ Built With

- **HTML5** — Structure
- **CSS3** — Styling, animations & responsive design
- **JavaScript** — Interactions & card navigation
- **Google Fonts** — Typography
- **Git & GitHub** — Version control
